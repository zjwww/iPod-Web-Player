## 0.1.2 — 2026-10-24

- Replace indefinite HTTP waiting and synchronous transfers with cancellable asynchronous work and short exit checks. Add Q/Enter/Ctrl+C foreground exit.
- Start in an independent hidden background process by default; add scoped stop/status commands, PID birth-time and entry-point checks, duplicate-start detection, bounded shutdown, and verified legacy-instance recovery. Avoid keeping redirected parent pipes alive.
- Add uncached native health and separate cached-app versus online/offline UI indicators. Preserve offline browsing and music after the HTTP backend stops.
- Add nine lifecycle regression scenarios alongside the existing ten audio/library tests. Preserve prior releases and document the WindowsTerminal crash evidence without claiming a native Terminal fix.

## 0.1.1 — 2026-10-24

- Center the original wheel click by producing identical stereo PCM channels while preserving mean stereo energy and preventing clipping. Music playback retains its original stereo signal path.
- Bundle a complete Noto Sans SC regular WOFF2 font and OFL license; fix Chinese header baseline, line boxes, menu rows, and metadata/progress spacing, including Chinese track text in the English UI.
- Open a version-specific app path to bypass prior offline caches while keeping the same-origin music database. Add font MIME support to both local servers and cache the font for offline use.
- Add focused audio regression tests and preserve v0.1.0 source, assets, documents, and delivery archive unchanged. Font build tools remain project-local and are not runtime dependencies.

## 0.1.0 — 2026-10-24

- First local prototype preserving Apple's original iPod wheel, monochrome screen, menus, backlight, click sound, and playback controls.
- Local file / optional folder import, drag-and-drop, MP3 ID3 metadata, artist and album-playlist grouping, and IndexedDB persistence with session-only fallback.
- Chinese / English interface and screen menus, responsive immersive player mode, capability-detected fullscreen, PWA manifest / offline shell cache, and Media Session integration.
- Original 24-second locally generated demo, Windows launcher without Node.js, and optional Node.js LAN server for phone previews.
- Unchanged upstream snapshot, provenance and hashes, five focused library tests, browser QA records, and separate English / Simplified Chinese documentation.
- Known limits: real-device Firefox / Safari / iOS / Android verification remains pending; codecs, volume, mobile fullscreen, storage, installation, and background playback depend on browser / OS.
