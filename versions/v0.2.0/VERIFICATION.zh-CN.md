## Safari 针对性实现及限制

用户手势内调用音频播放／恢复 context，测试音频采用标准 PCM WAV，滚轮采用 Pointer Events 和 touch-action；原生全屏不支持时回退沉浸视图，安装提示引导 Safari 添加到主屏幕。站内相对路径、限定路径的 manifest／缓存身份、离线单段范围 206 响应有测试覆盖。

**当前没有可用的真实 iOS／iPadOS Safari 会话。** 真实触摸转动、主屏幕安装、锁屏／后台播放、设备实际输出及存储回收尚未标记通过。桌面 Chromium 视口检查不等于 iOS／Safari 测试，需要在目标 iPhone／iPad 打开部署后的 HTTPS 地址验证。
